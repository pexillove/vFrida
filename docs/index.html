路径

IO 重定向

访客以为自己在写 /data/data/<pkg> 和 /sdcard，真实落盘在宿主私有目录的 v0 树下。

为什么 架构 物理根 生命周期 规则表 解析算法 生效通道 示例

如何劫持路径类 SVC

libc 符号 hook 挡不住手写 svc #0。这条用 seccomp-bpf 和 SIGSYS 把路径类系统调用补上。

为什么要劫持 两层拦截 seccomp 过滤器 SIGSYS 处理 安全页回放 与崩溃 SDK 共存 配置开关 日志与验证

如何让同 UID 应用计数保持为 1

客端和宿主共用一个内核 uid。同 uid 宿主进程的 cmdline 显示成客端包名之后，按包名去重只剩 1。

检测在数什么 为什么会得到 2 绕过 两条通道 故意不动的部分
